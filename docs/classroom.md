# ECG classroom

The home page opens the classroom. Choose any of the 75 objectives, then read the board or select **Teach me**. **Next** and **Previous** move through explanations, detailed teaching, the existing interactive diagram with a replayable step-by-step chalk tracing, approach, pitfalls and revision. Worked examples and practice questions use the existing curriculum and marking rules. Glossary terms open in Read / select mode.

Blackboard and Whiteboard are visual choices. Expand **Write on the board** to draw with chalk or pen, erase your ink, add a typed note, undo or redo. Annotations are saved per objective, stage and section in this browser. They are separate from mastery and are not included in the existing progress backup. Export a board PNG to keep an image copy. Clearing annotations can be undone until leaving the section. The eraser cannot remove teaching text.

The illustrated virtual guide reads the selected published lesson using browser speech synthesis. It waits for Next; it does not pretend to be a live teacher. Speech availability depends on the device. The existing optional AI tutor remains separately configured and does not become enabled through this update. Private original PDFs retain their existing access controls.

Verification: existing application tests plus board history, storage validation, coordinate bounds and ink/eraser rendering tests. Browser checks cover lesson navigation, whiteboard/blackboard controls, keyboard drawing, notes, undo/redo, section restoration, practice marking and PNG download. Speech failed honestly in the cloud browser; successful device audio requires a browser with a working installed voice.
